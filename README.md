# Пирамидальная сортировка с возможностью поиска

## Описание проекта
Программа на языке C реализует алгоритм пирамидальной сортировки (Heapsort) с дополнительными функциями:
- Генерация случайных массивов
- Ручной ввод данных
- Сортировка по возрастанию/убыванию
- Линейный и бинарный поиск
- Сохранение результатов в файлы

## Особенности реализации
- Использует бинарную кучу для сортировки
- Поддерживает работу с массивами до 10 миллионов элементов
- Имеет консольное меню для удобного взаимодействия
- Автоматически генерирует имена файлов с временными метками

## Требования
- Компилятор C (GCC, Clang, MSVC)
- Операционная система Windows (из-за использования windows.h)

## Сборка и запуск
1. Скомпилируйте программу:
```bash
gcc Piramida.c -o Piramida
```
2. Запустите исполняемый файл:
```bash
./Piramida
```
##Использование
Программа предлагает следующие варианты в главном меню:
1. Ручной ввод массива
2. Генерация случайного массива
3. Поиск числа в массиве
4. Выход

При сортировке можно выбрать направление:
1 - по возрастанию
0 - по убыванию

##Технические детали
- Сложность сортировки: O(n log n)
- Поддерживаются два вида поиска:
    - Линейный (O(n))
    - Бинарный (O(log n)) - только для отсортированных массивов
